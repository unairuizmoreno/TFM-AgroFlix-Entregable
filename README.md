# AgroFlix Entregable

Repositorio del Trabajo Fin de Máster *AgroFlix: sistema de recomendación de cultivos con rentabilidad ajustada al riesgo*. Contiene el cuaderno que reproduce el experimento descrito en la memoria.

## Contenido

- `AgroFlix.ipynb`: cuaderno con el experimento completo, ya ejecutado.
- `resultados/`: métricas de evaluación obtenidas en la ejecución del cuaderno.
- `requirements.txt`: librerías necesarias.
